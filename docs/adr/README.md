# Architecture Decisions

The current OAW architecture is defined by two accepted decisions:

| ADR | Decision |
| --- | --- |
| [0001](0001-static-policy-product.md) | Use the static Policy Set and Markdown Profiles as the complete product core. |
| [0002](0002-optional-machine-evidence.md) | Keep machine evidence in separate optional executables. |

New ADRs record only decisions that change these product boundaries. Routine
implementation, documentation, and release maintenance does not require an ADR.
