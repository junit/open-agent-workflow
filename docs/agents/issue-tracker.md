# Issue Tracker: GitHub

Issues for this repository live in GitHub Issues. Use the `gh` CLI and infer
the repository from `git remote`.

## Conventions

- Create, read, comment on, label, and close issues through `gh issue`.
- Skills that publish tickets create one GitHub issue per ticket.
- Use GitHub native issue dependencies for blocking relationships when
  available; otherwise add `Blocked by: #<number>` to the issue body.
- Apply `ready-for-agent` to fully specified implementation tickets.
- Pull requests are not a triage request surface.
