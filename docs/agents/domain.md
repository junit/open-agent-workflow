# Domain Docs

This repository uses a single domain context.

Before engineering work, read the root `CONTEXT.md` and relevant ADRs under
`docs/adr/`. Proceed silently when a referenced document does not exist.

Use the canonical vocabulary defined in `CONTEXT.md` in issues, plans, tests,
and implementation. Avoid synonyms that the glossary explicitly rejects.

Surface any conflict with an accepted ADR instead of silently overriding it.
