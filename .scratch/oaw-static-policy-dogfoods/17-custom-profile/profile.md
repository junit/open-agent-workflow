# Release Check

## Responsibilities

| Responsibility | Skill or action |
| --- | --- |
| Problem framing | `ecc:intent-driven-development` |
| Delivery planning | `superpowers:writing-plans` |
| Implementation and TDD | `ecc:tdd-workflow` |
| Review and remediation | `ecc:security-review` |

## Rules

- This is a partial Custom Profile. Policy Defaults remain active for
  Specification, Workspace preparation, Fresh verification, and Closeout.
- If the Host has no native `ecc:security-review` route, read the installed
  Skill rules and report that fallback while preserving Review and remediation
  ownership.
- Do not require Provider identity, cache paths, route contracts, Assurance, or
  Bridge evidence.
